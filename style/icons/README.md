# Icons

The landmarks' icons (decisions/015), from [Maki](https://github.com/mapbox/maki) 8.2.0, which its authors dedicated to the public domain under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). `make` draws them into a sprite of their own, `build/sprites/landmarks`, with [scripts/sprite.ts](../../scripts/sprite.ts).
